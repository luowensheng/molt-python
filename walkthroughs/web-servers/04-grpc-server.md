# gRPC Server — user-grpc

This walkthrough builds a gRPC user service using grpcio, grpcio-tools, protobuf, and SQLAlchemy. The service exposes `GetUser`, `CreateUser`, `ListUsers`, and `DeleteUser` RPCs, backed by a PostgreSQL database. You will generate Python stubs from a `.proto` file, run the server locally under molt, and ship a hermetic binary to a production host.

## 3. The protobuf definition

**`proto/user.proto`**

```protobuf
syntax = "proto3";

package user;

service UserService {
  rpc GetUser    (GetUserRequest)    returns (User);
  rpc CreateUser (CreateUserRequest) returns (User);
  rpc ListUsers  (ListUsersRequest)  returns (ListUsersResponse);
  rpc DeleteUser (DeleteUserRequest) returns (DeleteUserResponse);
}

message User {
  string id         = 1;
  string email      = 2;
  string name       = 3;
  string created_at = 4;
}

message GetUserRequest    { string id = 1; }
message CreateUserRequest { string email = 1; string name = 2; }
message ListUsersRequest  { int32 limit = 1; int32 offset = 2; }
message ListUsersResponse { repeated User users = 1; int32 total = 2; }
message DeleteUserRequest { string id = 1; }
message DeleteUserResponse { bool success = 1; }
```

## 6. Server implementation

**`user_grpc/server.py`**

```python
import os
import grpc
from concurrent import futures
from user_grpc.servicer import UserServicer
from user_grpc.generated import user_pb2_grpc

def serve(port: int = 50051) -> None:
    server = grpc.server(futures.ThreadPoolExecutor(max_workers=10))
    user_pb2_grpc.add_UserServiceServicer_to_server(UserServicer(), server)

    listen_addr = f"[::]:{port}"
    server.add_insecure_port(listen_addr)
    server.start()
    print(f"gRPC server listening on {listen_addr}", flush=True)
    server.wait_for_termination()

if __name__ == "__main__":
    serve(port=int(os.environ.get("GRPC_PORT", "50051")))
```

**`user_grpc/servicer.py`** (excerpt)

```python
import grpc
from user_grpc.generated import user_pb2, user_pb2_grpc
from user_grpc.database import get_session
from user_grpc.models import User

class UserServicer(user_pb2_grpc.UserServiceServicer):
    def GetUser(self, request, context):
        with get_session() as session:
            user = session.get(User, request.id)
            if not user:
                context.set_code(grpc.StatusCode.NOT_FOUND)
                context.set_details(f"User {request.id!r} not found")
                return user_pb2.User()
            return user_pb2.User(
                id=str(user.id),
                email=user.email,
                name=user.name,
                created_at=user.created_at.isoformat(),
            )

    def CreateUser(self, request, context):
        with get_session() as session:
            user = User(email=request.email, name=request.name)
            session.add(user)
            session.commit()
            session.refresh(user)
            return user_pb2.User(id=str(user.id), email=user.email, name=user.name)
```

```yaml
version: 1

project:
  name: user-grpc
  version: 1.0.0
  python: "3.12"
  description: "gRPC user service with SQLAlchemy + PostgreSQL"

deps:
  strategy: pyproject

include:
  - "user_grpc/**/*.py"
  - "proto/*.proto"

exclude:
  - "**/__pycache__/"
  - "**/*.pyc"
  - "tests/"

commands:
  default: serve

  serve:
    exec: [python, "-m", "user_grpc.server"]
    description: "Start the gRPC server on port 50051"
    env:
      GRPC_PORT: "50051"

  health:
    script: |
      python -c "
      import grpc
      import os
      from user_grpc.generated import user_pb2_grpc, user_pb2
      channel = grpc.insecure_channel(f'localhost:{os.environ.get(\"GRPC_PORT\", 50051)}')
      stub = user_pb2_grpc.UserServiceStub(channel)
      stub.ListUsers(user_pb2.ListUsersRequest(limit=1))
      print('gRPC health check: OK')
      "
    description: "Ping the running gRPC server"

  generate:
    exec:
      - python
      - "-m"
      - grpc_tools.protoc
      - "-I"
      - proto
      - "--python_out=user_grpc/generated"
      - "--grpc_python_out=user_grpc/generated"
      - "proto/user.proto"
    description: "Regenerate protobuf stubs from proto/user.proto"

env:
  PYTHONUNBUFFERED: "1"

integrity:
  verify_on_install: true
```

## 11. Tips

- **Proto files ship in the binary**: the `include` glob includes `proto/*.proto`, so clients can extract the schema with `molt inspect --files`. The pre-generated Python stubs are included in `user_grpc/generated/` and ship alongside.
- **Reflection**: add `grpcio-reflection` to your deps and enable it in `server.py` for tools like `grpcurl` and `Postman` to introspect your service without the proto file.
- **TLS**: switch to `grpc.ssl_server_credentials(...)` in production. Cert paths passed via environment variables at runtime — never embedded in the binary.
- **Re-generating stubs**: run `molt run generate` after any `.proto` change, then rebuild: `molt build`. The `generate` command is a development-time task only; the stubs are committed to the repo and ship in the binary as regular `.py` files.
- **Concurrent builds for multiple targets**: use a CI matrix (`ubuntu-24.04` for Linux/amd64, `ubuntu-24.04-arm64` for Linux/arm64). The gRPC C extensions are platform-specific so each target must build natively.
